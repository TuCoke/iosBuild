# iOS Agent 接入状态与待办（2026-11-12）

本清单区分源码实现、编译检查和真实设备验收。范围是本轮 iOS SDK/Agent 接入，不是整个 v2 项目的全量审计。后续状态变更应更新本清单，不能以接口存在或模型自述代替业务效果。

## 一、当前实际链路

```text
本地控制台 / MCP / AI
  → 本地服务端（Session、Operation、租户及栅栏）
  → 电脑 iosremote 联调桥
  → FRP
  → iPhone AgovHost 与 iOS SDK
```

当前真实设备仍走电脑桥。独立手机端 `agent/ios` 已有实现和宿主设置页，构建镜像已同步，但不能把电脑桥的测试结果算成手机原生 Agent 的验收。先前 IPA 编译安装不代表本次最新修改已包含在该 IPA。

## 四、尚未完整实现或接入的能力

- OCR、找图、YOLO 等 SDK 能力未完整映射为 iOS Agent 命令；必须分别核查依赖、参数与实际效果。
- 完整文件/存储操作、更多 AX 动作、独立应用列表面板尚未补齐。
- 手机本地脚本下发与云控任务/Session 的完整编排尚未补齐；SDK 本地解释执行不等于云控已能下发。
- iOS SDK 云端升级、重启后健康确认、失败回退的完整云控编排尚未验收，不能沿用 Android 内核包安装逻辑。
- 原生 Agent 暂走 WS H.264；iOS WebRTC 未接入。
- 输入插入/替换语义仍需跨平台明确，不能把 iOS Unicode 输入当作 Android IME 的全部行为。
- 点击、输入等未知副作用仍需安全核对与恢复闭环，不能直接仿照 open_app 全部取消隔离；任务失败后的队列和人工接管展示也需完善。

## 五、验收矩阵

| 场景 | 当前结论 | 后续验收要求 |
| --- | --- | --- |
| 切到设置/天气后后台 API、视频 | 短时通过 | 第一轮约 96 秒、2879 帧、最大收帧间隔约 0.53 秒；不等于小时级后台保证，也未对每帧画面逐一校验 |
| 宿主进程存活 | 本轮保持同一 PID | 息屏初始现场可访问，观察到约 18 分钟 uptime；不等于连续 18 分钟全程专门测试 |
| 长时间投屏 | 未通过 | 已复现 120 秒截止；修复后需超时长测试与主动停止后的编码器释放验证 |
| 自动息屏/主动锁屏/唤醒 | 部分事实已测，整体未通过 | 初始真实息屏现场可访问，wake 可点亮但当时仍锁定；之后主动熄屏未确认。需要视觉与 API 对照；不承诺绕过密码锁 |
| 联调桥进程中断 | 通过有限范围 | 手动停止电脑桥，服务端识别下线；重启后约 1 秒上线，日志和栅栏保留。这是进程恢复，不是手机断网 |
| 手机 Wi-Fi 断开/网络切换 | 未测 | 需手机侧配合或可恢复的故障注入，覆盖 FRP 重连、旧连接释放、任务结果未知与排队恢复 |
| 原生手机 Agent 持续连接/视频 | 未测 | 停止电脑桥后单独测试原生入口，不能同时注册冒充通过 |
| 当前最新源码 Apple 编译与 IPA | 待验证 | 本地 Go 编译和镜像检查不替代 Apple SDK/cgo、ObjC 编译及安装 |
| Android+iOS 同时在线及混合群控 | 未测 | 平台隔离、各自能力、同设备串行、多设备并行、取消与权限 |
| 多任务排队、取消、重连、服务重启 | 尚未完整真机覆盖 | 包括任务 A 超时后任务 B、强杀中途动作、迟到回执，避免重复副作用 |
| 后台长稳与系统资源压力 | 未测 | 长时间后台、内存压力、音频中断、系统回收、低电量、旋转及弱网 |

## 六、发布与验证说明

本轮已执行相关 Go 定向测试、Agent WS 测试、服务端 open_app 隔离策略测试、本地服务和桥编译、iOS 构建镜像同步及平台边界检查；具体未测项按上表保留。没有宣称全项目测试通过。

提交不包含本地数据库、执行日志、密钥、IPA/ZIP、反编译参考样本。源码提交到 Gitee v2 后不自动代表公网服务已部署，也不代表 GitHub 独立 iOS 构建仓库已同步和重新出包。

后续建议顺序：修复投屏到期恢复与息屏确认 → 原生 Agent 真机接管 → 真实断网/重连与任务取消 → Android+iOS 混合验收 → 扩展能力。


原生云端接入新增代码与发布顺序见 [云端接入交接](ios-cloud-agent-handoff.md)。本轮只提交代码和构建，不执行部署。
