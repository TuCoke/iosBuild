# iOS 穿透配置界面

主界面右上角 **穿透设置** 支持填写并保存服务器 IP/域名、frps 连接端口、frps token、手机本地端口、公网映射端口、隧道名称和 TLS 开关。

默认服务器 `49.235.187.13`、连接端口 `7000`、本地/公网端口 `18990`。frps token 需要在 UI 手动输入，不写进源码。此 token 与调试 API 的固定 `1234567` 是两套凭据。

## 操作

1. 打开“穿透设置”，填写参数后保存。
2. 返回主界面，点击“启动穿透”。缺少配置时会提示并打开设置。
3. 点击“隧道状态”查看实际进程和 frpc 日志；必须检查服务端登录、代理注册是否成功，不能只看 PID。
4. 更换服务器或端口：保存配置，先停止，再启动。保存不会中断正在运行的连接；启动按钮也不会重复拉起进程。

服务端安全组、防火墙需放行 frps 的 TCP 7000 和选定的公网映射端口。多台设备需要不同的隧道名称与公网端口。

## 保存位置与执行边界

- 宿主设置代码：`host/ios/Sources/AGTunnelSettingsViewController.h/.m`。表单可滚动、token 输入隐藏；对地址、端口、名称与必填 token 做校验。
- 普通参数保存在 NSUserDefaults；frps token 单独存 Keychain，读取/保存失败明确提示，不回退为普通偏好明文。取消不会保存。
- 启动按钮使用已保存参数调用现有 `tunnel.start`，不再传空 JSON；启动探针不再自动尝试连接服务器。
- frpc 运行配置仍需明文 token，写到 `Documents/Tunnel/frpc.toml`，权限 0600。日志与 PID 同目录。穿透模块单独定位 Documents，不修改脚本文件能力的全局根目录。
- 不在 app.log 中记录启动 payload；日志中仍可能含服务器地址等调试信息。
- UI 保存不等于 frps 已连通，也不解决 App 后台挂起。服务器与设备的实际连接需要安装新包、填入配置后验证。

本轮验证：穿透模块已有 Go 测试、宿主静态检查通过；新增 UIKit/Keychain 页面仍需 Apple CI 编译及安装后交互验证。

## 服务器凭据预填

按用户提供的完整参数，首次默认本地/公网端口调整为 `18989`，服务器仍为 `49.235.187.13:7000`，隧道名为 `agov-iphone`。该配置暴露本机 18989 的状态接口，外部用 `http://49.235.187.13:18989/status` 查看；如需完整调试 API，需在 UI 选择手机本地端口 18990，并调整对应公网端口与访问路径。

GitHub 仓库 Actions Secret `IOS_FRPS_TOKEN` 已配置。签名前将其注入安装包 Info.plist 的 `AGDefaultFrpsToken`；没有 Keychain 记录且服务器仍匹配时自动预填。已保存的 token 和端口不会被新包覆盖。修改服务器后不会误用旧服务器的默认凭据。

Git 源码和构建日志不包含预填密钥，但安装包内的默认值可以被提取，不能将打包视为保密机制。用户在设置中保存后仍使用 Keychain；SDK 运行所需的 frpc TOML 仍按 0600 文件权限写入。
