# iOS 原生 Agent 云端接入交接

日期：2026-11-12。本轮仅完成代码、静态检查及源码提交，不部署服务器，不切换手机，不宣称原生云端真机验收通过。

## 正式链路

手机 AgovHost 内独立 iOS Agent → `wss://frpc.api-y.cn/agent` → 已有云端后端 → 控制台/MCP/任务。

所有手机使用同一个入口，由设备 ID、租户凭据和各自连接区分。FRP 保留为远程诊断通道，不作为正式 Agent 的设备路由。Agent 设置页未保存配置时预填上述地址；已保存地址不自动覆盖。凭据使用云控接入卡密，不使用 FRP token、调试口令或浏览器登录密码，不在源码中预置。

## 本轮补齐

1. 注册确认增加 `serverTimeMs`，云端服务与本地内核的注册入口同时填入。Android 不依赖此新字段，原有协议字段保持。
2. iOS 使用服务端时间基准与本地单调计时核对 `deadlineAt`，不修改手机系统时间，不因手机快/慢 273 秒而直接过期。保守扣除握手往返耗时，不放宽服务端期限；排队也消耗预算，已过期则在开始前明确拒绝。
3. 单条动作仍受 125 秒上限、上游取消、会话及持久栅栏约束。该上限针对动作，不是视频时长；原生视频已有独立生命周期。
4. 缺少服务端时间基准时明确提示先更新后端，不悄悄退回手机墙上时间。应先部署新后端，再使用新 IPA。
5. 原生 Agent 日志改为私有 Agent 数据目录下 `journals/<云控地址摘要>`。切换服务器不共用栅栏，切回原地址保留原记录。更换域名会视为新的执行命名空间，应在停止和现场核对后进行，不能通过改地址绕过未处理任务。
6. 如果存在旧版非空 `journal`，拒绝猜测迁移归属，不清空旧记录。首次正式接入通常没有旧原生任务日志；若确有旧日志，需要单独核对归属再迁移，不能删除日志来解锁。

## 发布顺序（本轮未执行部署）

1. 服务端更新本轮 v2 后端与控制台，确认反向代理转发 WebSocket 及 Authorization，请求使用有效 TLS。
2. 为目标租户准备有效的云控接入凭据，不把 FRP token 当作 Agent 凭据。
3. 安装包含本次修改的新版 AgovHost。电脑联调桥和手机原生 Agent 不同时接管同一台手机。
4. 在手机 Agent 设置页填写地址与凭据，保存后连接。收到匹配设备 ID、连接代次和服务端时间的注册确认才显示 online。
5. 依次验收上线、应用列表、截图、点击/滑动/输入、超过 120 秒原生视频、切 App、息屏、断网重连、取消及后续任务。保留 FRP 诊断入口；原生连接失败时不能自动启动旧桥并混淆结果。

## 检查边界

新增时间偏差、长连接预算、过期拒绝及不同服务端日志隔离的回归用例。本轮按要求仅编译测试代码（`go test -run '^$'`）、Go 构建、go vet、iOS 目标 Go/stub 交叉编译和构建镜像/依赖边界检查，不运行这些用例，也不操作真机。

Windows 上 Android 本地内核模块缺少 OCR/YOLO 原生依赖，不能在此环境完成该模块构建；不因此声称全项目静态编译通过。完整 Apple SDK/cgo、ObjC 壳编译需要 GitHub macOS 工作流；推送触发构建不等于构建成功。

仍待修复和验收：联调桥调试视频 120 秒自动结束、熄屏效果与状态核对、模型工具按平台限制、应用别名、真实断网、小时级后台、混合设备及正式云端端到端验收。原生视频实现不使用调试接口限时，但必须真机验证才能确认已解决正式链路断流。
